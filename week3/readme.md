# JavaScript Fundamentals – Lab Exercises and Portfolio Activity

## 1. Project Overview

This project was developed as part of the **CN5006 JavaScript Fundamentals Lab Session**, prepared by Dr. N. Qazi.

The purpose of this project is to demonstrate my understanding of fundamental JavaScript programming concepts using Node.js. The exercises cover variables, functions, arrow functions, user input, loops, conditional statements, classes, modules, date and time handling, and built-in Node.js modules.

The project also includes a portfolio activity in which the program collects student details, displays the current date and time, identifies a favourite programming language, and calculates a verification number from the last four digits of a student ID.

## 2. Learning Objectives

The main objectives of this project are to:

- Understand JavaScript syntax and variables.
- Accept user input from the terminal.
- Display formatted output using `console.log()`.
- Work with JavaScript functions and arrow functions.
- Use conditional statements and loops.
- Manipulate strings and convert characters into numbers.
- Create and import reusable modules.
- Understand classes, constructors, objects, and methods.
- Work with dates and times.
- Explore built-in Node.js modules, including `os` and `util`.
- Run JavaScript programs using Node.js and interpret their output.

## 3. Technologies Used

- **JavaScript:** The programming language used to implement the exercises.
- **Node.js:** The JavaScript runtime used to execute programs outside a web browser.
- **npm:** The Node.js package manager used to install external dependencies.
- **prompt-sync:** A package that allows the program to receive user input directly from the terminal.
- **Visual Studio Code:** A code editor used to write and manage the project files.
